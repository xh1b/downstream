# Mathematics, implementation, and paper review — 2026-09-10

The numerical core is useful as a conditional scenario model, but it is not
yet a validated causal model of the full displacement-to-descendant system.
This review repaired five implementation defects and updated the paper.
Mortality source extraction, the place counterfactual, and county likelihood
semantics still need substantive corrections before expanding the graph.

## Scope and evidence

Reviewed the current, already-modified workspace, preserving prior work.
Traced ledger operations, mortality/survival, scenario counts and prediction,
place pooling, sampling, analytic moments, sensitivity, policy comparison,
study synthesis, county likelihoods, scoring, forecast registration, and
paper generation. This is a targeted mathematical and code review, not a
fresh extraction audit of every parameter or a security audit.

The starting suite passed **577 tests**. New checks use analytic oracles and
cross-surface consistency rather than just reproducing current outputs.
Source checking included a downloaded and visually inspected Sullivan–von
Wachter Table 5, PDF page 54 of
[NBER Working Paper 13626](https://www.nber.org/system/files/working_papers/w13626/w13626.pdf).
No production parameter values or historical score targets were changed.

## Repaired implementation findings

### P1 — fixed copula ranks invalidate correlated-block Sobol designs

`distributions.apply_rank_correlation` created `Random(0)` internally on
every call. Consequently, plans A and B with different user seeds shared
the same rank ordering; only within-stratum jitter changed. Swapping a
block then changed almost nothing, producing near-zero total indices even
for strongly influential inputs.

**Oracle:** three Uniform(0,1) inputs, Spearman correlation .5 between the
first two, and output `X0 + X1 + X2`. Uniform marginals make Spearman equal
Pearson here. The joint block has variance `3/12`, the independent singleton
`1/12`; first and total indices must be .75 and .25. Before repair, both
totals rounded to zero. After repair (4,096 draws, seed 7), first/total are
.7377/.7479 and .2351/.2509. Plans now use their seeded RNG for copula scores.
Same-seed runs reproduce; different seeds produce independent designs.

This deliberately changes correlated Monte Carlo draws at historical seeds.
The paper's source hash, rather than parameter version alone, identifies the
implementation. The low-level helper retains a deterministic default for
direct calls; all production plans pass their RNG explicitly.

### P1 — county expected and predictive mortality used different baselines

`compute_counts` pooled the county baseline, but `sample_counts` passed the
original national baseline to `_predictive_mortality`. Thus `p0` and `p1`
did not describe the same survival model as the expected-count calculation.

Both layers now use the resolved baseline. Output records the annual
probability used and the cumulative counterfactual probability. A test
intercepts binomial probabilities and checks them against the pooled
baseline and the independent odds-to-risk identity.

### P2 — custom chains accepted disconnected graph edges

The whitelist checked allowed operations for individual links but ignored
adjacency. A worker-earnings direct effect could be followed by the
child-to-grandchild transmission, or a generation could be skipped.
`validate_chain` now compares each destination with the next source node.
Public simulate/infer routes already call this validator. Low-level ledger
algebra remains available for explicitly constructed research experiments;
it should not be confused with a general causal graph validator.

### P2 — Monte Carlo ignored the chain starting value

`simulate_chain(base=.8)` discarded `base` when constructing the ledger.
A standalone gap step therefore returned 1 rather than transmitting the
supplied gap. The value now reaches `chain` and `start`. A pinned .5
transmission with base .8 returns .9 at every quantile.

### P2 — legacy additive mortality received a probability interpretation

The legacy count expression is not bounded by cohort size. Feeding it into
a binomial layer and clamping the implied risk can silently change the
expected contrast. Legacy additive results now retain expected counts and
explicitly decline predictive counts; the survival model remains eligible.

## Unresolved mathematical and evidence findings

### P1 — mortality timing is not source aligned

The working-paper table contains early effects; “unidentified” was an
incorrect description of missing implementation. Column 3 gives log-odds
coefficients .982, .685, .549, .240, and .127 for displacement, offsets +1,
+2–3, +4–5, and +6+, respectively. The stored .983 peak is from column 2;
the stored .127 sustained coefficient is from column 3 despite its note
saying column 2. These are different specifications.

With displacement occupying follow-up year 1, source offset +6 starts
follow-up year 7. The current kernel starts it in year 6 and omits positive
early coefficients. Its API option name is historical, not evidence of
fidelity. The manuscript, README, and output assumptions now say so.

**Next fix:** reconcile working-paper and published versions, extract one
coherent profile with standard errors and source locators, version the data,
and define time using offsets from displacement. Test each phase boundary
and recompute V1; do not choose a specification by whether it improves fit.
Do not invent the missing covariance among phase estimates.

### P1 — place adjustment fails a null-displacement check

The optional place path applies `g_place = M*g` and reports loss `1-M*g`.
At `g=1` it reports `1-M`, not zero. With shipped San Francisco data
(`06075`), setting the direct displacement effect to one yields
`g_place=1.064075194`. This is a place-level gain attributed to a null
displacement effect.

The [Chetty–Hendren design](https://hendren.scholars.harvard.edu/publications/impacts-neighborhoods-intergenerational-mobility-i-childhood-exposure-effects)
estimates exposure to neighborhoods; it does not itself identify an
interaction with displacement. Decide whether place changes both arms'
earnings baseline or modifies the treatment effect. A shared level baseline
would give `M*(1-g)`, but that is a candidate estimand, not a newly established
causal bridge. Until resolved, use national child dollar results as the
reference and label county child contrasts exploratory.

### P1 before county integration — person-years are not binomial trials

`county_rates.beta_binomial_posterior` treats `person_years-events` as
binomial failures, permits fractional person-years, and names the result a
count-likelihood posterior. General person-time is not a count of
independent Bernoulli trials. The production baseline also uses a crude
rate as an annual death probability. The
[CDC definitions](https://archive.cdc.gov/www_cdc_gov/csels/dsepd/ss1978/lesson3/section3.html)
distinguish these quantities.

Use a Poisson likelihood with a gamma prior for event/person-time rates, or
require genuine fixed-window cohort trials for beta-binomial updating.
Under constant hazard, convert rate `lambda` to risk `1-exp(-lambda)`;
use life-table probabilities when available. Validate population/window
compatibility against national-prior metadata, which the current scalar
`national_rate` argument cannot establish. Keep this experimental module
out of scenario baseline uncertainty until that contract is enforced.

### P2 — transmission is an approximation and a causal assumption

Gap propagation `1-t*(1-v)` is algebraically coherent. If `t` denotes a
constant log elasticity, however, the finite-change mapping is `v**t`;
the shipped rule is its Taylor approximation at one. Neither formula
turns between-family persistence into an identified intervention response.
Add a named log-elasticity variant and causal-role metadata; do not silently
replace the default or describe distant descendants as causally validated.

### P2 — synthesis compatibility and intervals are weaker than their names

Grouping on `(link, scale)` does not check population, time horizon, study
overlap, or design. DerSimonian–Laird with plug-in 1.96 intervals ignores
heterogeneity-estimation uncertainty. The
[Cochrane methods guidance](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-10)
documents problems with few-study prediction intervals. Add explicit
compatibility admission, overlap handling, and REML/Hartung–Knapp or a
declared Bayesian sensitivity analysis. Preserve the present separation
between synthesis and production-parameter admission.

### P2 — stabilize first-order sensitivity at small output variance

After fixing independent ranks, the uncentered first-order Saltelli product
can still have large finite-design noise when the output mean dwarfs its
standard deviation. A shipped grandchild block run (base 256, seed 7)
returned first-order -.384 for the transmission coefficient while its total
index was .0753. Negative estimated indices are possible at finite sample
sizes; this is not negative causal influence. Center outputs consistently
before the covariance product, add invariance-to-constant-shifts tests, and
report seed variation for dependent-block experiments as well as independent
Sobol. Do not clip estimates to [0,1] to hide design error.

## What remains sound, conditional on assumptions

- The odds-to-risk identity and survival product are mathematically coherent
  for a supplied annual probability and declared phase durations.
- Gap and level envelopes use all endpoint corners, retaining signed effects.
- Independent analytic moment propagation is valid for supported marginals;
  approximate normal/Cornish–Fisher quantiles remain approximate.
- CRPS uses the correct sorted-pair identity. Scoring published point
  estimates still omits their measurement uncertainty.
- Support envelopes, parameter intervals, and realized-count variation are
  distinct. The API's “posterior-predictive” name does not make elicited
  cross-study parameter bands a fitted Bayesian posterior.
- V1 now scores the shipped mortality kernel. It retains both male mortality
  misses and earnings misses; V2 remains blocked and V3 has no real result.

## Recommended sequence and acceptance criteria

1. **Correct existing headline estimands:** coherent mortality time profile,
   rate/risk semantics, and same-place counterfactuals. Require exact phase
   boundary tests and zero response to a null intervention.
2. **Strengthen data contracts:** edge causal role, dose, outcome scale,
   population, follow-up, study ID, covariance provenance, and missingness.
   Enforce these at admission and composition rather than only documenting
   them. Freeze validation constants in cited input files.
3. **Complete one independent event validation:** matched exposure and
   outcome geography/window, independent bridge, observation uncertainty,
   and a frozen scoring protocol. Obtain an independent timestamp for one
   prospective forecast; retain misses.
4. **Add uncertainty that changes decisions:** proper county likelihoods,
   baseline and exposure draws, coherent study synthesis, and paired shared-
   parameter policy contrasts. More draws cannot fix estimand mismatch.
5. **Expand supported heterogeneity:** age/sex/tenure strata and separate
   manufacturing/high-tech employment responses before distant generations
   or additional overlapping family paths. Validate symmetry assumptions
   when applying job-creation multipliers to job destruction.

The updated paper contains the corrected implemented equations, current
generated scorecards, and these limitations and priorities. Its content hash
now includes the manuscript, generator, paper references, build recipe, and
dependency lockfile as well as model/data inputs.
