## Classification and runtime use

Precision tier describes extraction provenance. `evidence_role` describes applicability;
ledger `causal_role` describes how the coefficient is used. These are separate axes.
A conditional source coefficient can be used in a structural projection. `direct` means
the source estimates the named exposure–outcome contrast, not that transport is automatic.

The 74 parameters comprise 0 admitted, 33 conditional, 6 structural, 35 boundary.

`named_adapter_only` means generic chaining is refused; it does not assert that every
adapter is a causal effect. Boundary evidence can be a separate-exposure causal estimate
or an association. Its design and source notes still govern interpretation. Findings and
source contrasts never become parameters merely by being loaded.

The fetal dose-response rows demonstrate the two axes: their source applicability is
conditional, while their use after a displacement-induced birth-weight shift is structural.
The married-cohort dissolution row is an observed counterfactual share, not a treatment effect.

The chain kind is permission for the validated generic chain, not an exhaustive consumer map.
Named adapters additionally enforce input type, units, horizon and population contracts.

## Dependence and structural assumptions

Correlation entries preserve a declared modeling choice or source-backed direction;
they are not new intervention-effect estimates.

| Pair | Spearman | Justification |
| --- | --- | --- |
| displacement->worker_earnings / earnings_shock->mortality_peak | -0.5 | Direction citable, magnitude DECLARED: both rows are calibrated on the Sullivan & von Wachter 2009 bad-case sample (early-1980s Pennsylvania recession); the mortality rows' own scope notes record the Davis & von Wachter 2011 caveat that earnings losses AND mortality effects are smaller in normal times, and the earnings row's band spans that same cross-study recession-depth spread. A coherent draw pairs the deep-loss edge of the earnings multiplier with the high end of the mortality response (deep case), or the shallow edge with the low end (normal times) - in multiplier-value space that is a NEGATIVE rank correlation. The papers report no sampling covariance, so -0.5 is a declared moderate coupling, not an extracted coefficient. Applied via Iman-Conover: marginals preserved exactly |
| displacement->worker_earnings / earnings_shock->mortality_sustained | -0.5 | Same justification as the peak row: declared moderate negative coupling between the long-run earnings multiplier and the sustained-mortality response, both calibrated on the same bad-case sample (Sullivan & von Wachter 2009; Davis & von Wachter 2011 smaller-in-normal-times caveat recorded in both rows' scope notes); magnitude DECLARED, direction citable |

Additional structural choices live in code and inputs: same-place loss scaling,
intergenerational repetition, birth-weight mediation, fixed or declared mortality
